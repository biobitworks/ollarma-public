# Ollarma — Academic Use Addendum

**Version 1.0 · 2026-06-10**

This Addendum supplements the base **Apache License, Version 2.0** (see `LICENSE`)
under which the Ollarma core substrate is released. It grants additional,
no-cost rights to qualifying academic and non-profit research users and clarifies
the terms under which the research extensions may be used.

## 1. Who qualifies

"Academic User" means: an accredited university or college; a non-profit research
institute; or an individual using Ollarma solely for non-commercial academic
research, teaching, or coursework. Use by or on behalf of a for-profit entity is
**not** covered by this Addendum and requires the Commercial License
(`LICENSE-COMMERCIAL.md`).

## 2. Grant

Subject to Section 4, the maintainer grants Academic Users a worldwide,
royalty-free, non-exclusive license to use, reproduce, modify, and create
derivative works of the Ollarma core **and** the research-extension components
(pre-registration / claim-ceiling tooling, provenance/PROV sidecars, evaluation
rubrics, reproducibility runbooks) for non-commercial academic research.

## 3. Conditions

3.1 **Attribution + citation.** Publications, preprints, posters, or theses that
use Ollarma must cite the project. A `CITATION.cff` is provided for this purpose;
where one is not yet present, cite as: *"Ollarma — a local verification layer for
AI-assisted computational research"* with the repository URL and commit hash used.

3.2 **Share-back (best effort).** Where institutional policy permits, Academic
Users are encouraged to contribute back evaluation artifacts, reference datasets,
and bug fixes under the same terms.

3.3 **No commercial use.** Output, derivatives, and the software itself may not be
sold, offered as a paid service, or embedded in a commercial product under this
Addendum. For any commercial use, see `LICENSE-COMMERCIAL.md`.

3.4 **Safety features are not restricted.** Nothing in this Addendum limits use of
the verification, guardrail, claim-ceiling, or provenance mechanisms; those are
free in every tier.

## 4. Precedence and base license

The base Apache-2.0 license governs the core substrate for all users. This
Addendum only **adds** rights for Academic Users to the research extensions; it
does not remove or restrict any Apache-2.0 right in the core. Where this Addendum
conflicts with Apache-2.0 for the core substrate, Apache-2.0 controls for the
core.

## 5. No warranty

Provided "AS IS", without warranty of any kind, to the fullest extent permitted
by law. See Apache-2.0 §7–8.
