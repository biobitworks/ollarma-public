# Review Packet Examples

This directory is for committed, redacted protocol examples only.

Live review packets belong under:

```text
~/.ollarma/swe_session/review-requests/YYYY-MM-DD-<slug>.md
```

Do not commit raw transcripts, secrets, provider payloads, or broad local
runtime state. If an example is useful for tests or protocol review, copy only
the minimal redacted case into this directory.
